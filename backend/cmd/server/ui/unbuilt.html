The API is running. The console is not bundled into this binary.

This server was built without the front end. The fleet API and the telemetry stream are live under /api/v1; only the user interface is missing.

Build both halves into one binary:

pnpm run build
./bin/server

Or run the two halves separately while developing, with the console on :5173 proxying to this API: 

pnpm run dev
